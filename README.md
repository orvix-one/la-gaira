# La Gaira — Dashboard

Dashboard analítico multi-sucursal.

## Requisitos

Node 24 LTS (ver `.nvmrc`).

## Instalar

```
npm install
```

## Correr

```
npm run dev
```

## Datos

El excel de muestra está en `data/raw/SampleDataLaGaira.xlsx`.

Ver `AGENTS.md` (reglas, comandos, estructura) y `ARCHITECTURE.md` (arquitectura, fases del proyecto).
